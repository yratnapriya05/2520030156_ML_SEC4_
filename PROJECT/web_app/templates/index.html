    About this project

    This web application is the demonstration layer for a machine learning project that detects plant leaf diseases with a convolutional neural network. The classifier was trained in Google Colab on a PlantVillage color-image subset (38 classes, 17,910 images) using transfer learning from ImageNet-pretrained MobileNetV2. The website sends your uploaded image to a Flask backend, which loads that same trained .keras file and returns the predicted class.

    How it works

    1. You upload a JPG, JPEG, or PNG leaf photo.
    2. The backend converts it to RGB and resizes it to 224 × 224 with bilinear interpolation — the same size used during training.
    3. Pixel values stay in the 0–255 range. MobileNetV2 scaling is already inside the saved model, so it is not applied a second time.
    4. The model outputs 38 softmax scores. The class with the highest score is shown, along with that score as a confidence percentage.

    Model information

    Architecture
    MobileNetV2 (ImageNet weights, frozen base) + global average pooling + dropout (0.3) + dense softmax head
    Framework
    TensorFlow / Keras
    Input
    224 × 224 × 3 RGB
    Loss
    Sparse categorical crossentropy
    Reported test results
    Accuracy 92.29% · Loss 0.2192 (held-out PlantVillage subset split from the notebook)
    Model file
    web_app/models/plant_disease_mobilenetv2.keras
